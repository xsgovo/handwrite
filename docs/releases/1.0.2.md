# 随手写 1.0.2

| 项 | 值 |
|---|---|
| 版本 | 1.0.2（versionCode 2） |
| 发布日期 | 2026-11-17 |
| 最低系统 | Android 12（API 31） |

本版把界面整体重做了一遍，同时修掉了页面面板拖拽排序里几处长期存在的错位与卡顿，
并让导出、分享、撤销在大文档下更省资源。数据结构与文件格式未变，可直接覆盖安装。

## 界面

- 换成一套自绘的扁平图标集（24dp 网格、圆角端帽、双层双色填充），替换原先的 Material
  图标，全应用共用同一套线宽与圆角。
- 工具栏按钮改为圆角胶囊造型，主工具行可横向滚动，不再为塞下所有按钮而压缩点击区域；
  笔、橡皮、背景、画布选项集中到统一的子菜单组件，不再各自一套版式。
- 设置、导出、文档库三页统一版式：分节带图标与分隔线，导出格式改为带图标与一句话
  说明的卡片。
- 书写相关能力不变：画笔与笔宽、笔画橡皮与像素橡皮、撤销重做、缩放锁定、背景与页面
  管理、四种导出格式，均保留，入口按新工具栏重新排布。

## 导出与渲染

- 长图导出时同一背景不再逐页重复解码。PDF 光栅化本身开销很高，此前每页都要重来一次；
  现在同一背景复用同一张位图，页数越多收益越明显。
- PDF 背景按导出分辨率光栅化，不再被限制在原始页面尺寸以内。此前高分辨率导出里
  背景会被放大而发虚，笔迹清晰、背景模糊；现在两者一致。图片背景仍只降采样、不放大。
- 导出与分享结束后主动回收背景位图，避免长文档导出后仍占着几张大图。
- 分享与导出共用同一套分辨率与压缩映射。此前两条路径各有一份实现，同一设置下可能
  产出不同的清晰度与体积，现在只有一个来源。
- 屏幕绘制复用变换矩阵，减少书写与滚动时每帧的对象分配。

## 页面面板

- 修复拖拽排序落地时视口锚定偏移，导致第一页看不见的问题。
- 修复松手后落位动画重复播放、被拖页面从其他页面下方掠过的问题。
- 修复列表滚动后尾部页面拖不动、被错误压缩进视口内格位的问题，现在任意页面都能
  拖到包括末尾在内的任意位置。
- 边缘自动滚动改为随触边深度与手势速度自适应，启停更平滑。
- 拖拽、删除页面、松手落位后，不再把选中页自动顶到面板最顶端。

## 撤销

- 撤销/重做的容量统计改为增量维护。此前每一步操作都要遍历整个历史栈求和，命令累积到
  上百条时这笔开销会落在每次书写之后；现在与历史长度无关。

## 安装与升级

- 覆盖安装即可，本地笔记全部保留：文档存在设备本机的数据库里，应用没有账号、没有云同步，
  也不会在升级时重建或迁移数据。
- `versionCode` 从 1 提升到 2，可直接覆盖 1.0.1。
- 若系统提示"未安装"，通常是签名不一致（例如装过自己编译的包），卸载旧版后重装即可，
  卸载会一并删除本地文档，请先导出备份。

## 已知限制

- 长图导出会把所有页面合成一张大位图，页数很多时内存峰值较高，目前靠导出分辨率档位控制。
- 单独删除页面不可撤销；撤销历史只在本次运行内有效，退出应用后不保留。
- 原生包目前只支持导出，导入尚未实现。
